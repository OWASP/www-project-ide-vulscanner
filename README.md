# IDE VulScanner - Spectral Linting Setup

This extension integrates Spectral for security linting in VS Code.

## Features
- Automatically scans code on save
- Uses OWASP security best practices
- Displays results in the Problems Panel

## Setup
1. Install dependencies: `npm install`
2. Run the extension: `npm run compile`
3. Open any JSON/YAML file to trigger Spectral linting.
